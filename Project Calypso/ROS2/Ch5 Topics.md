## What is a topic?
![[Pasted image 20260827203637.png]]

- can have 0 subscribers (published but no one listening)
- can have 0 publishers (subscribed but receiving nothing)


![[Pasted image 20260827204422.png]]
- a node may publish on several topics/subscribe to several topics
- Thus, inside one node, you can have any number of publishers and subscribers to different topics with different data types. A node can communicate with several nodes at the same time.

- Topics are used to send/receive streams of information. Camera images, or stream of commands for a robot's movement.
